1. 시제품이 무엇인가

단순 모니터링이 아니라 기준선 → 추천/제어 → 로그 → 전후비교 → MRV 증빙이 한 줄로 이어지는 시스템이다. 양식장의 전력·용존산소·급이·폐사·생산량 기록에서 KPI 5종을 산출하고, 잠긴 기준선 대비 전력 절감을 Scope 2 탄소저감 성과로 환산해 산식 전문과 배출계수 출처를 함께 인쇄하는 MRV 리포트까지 제품 안에서 닫힌다.

7. 심사용 시연 시나리오 (5분)

  1. 공개 데모 열기 (1분) — QR 로 /mrv/demo. 상단 안내(시연 자료, API 호출 없음)와 사슬 6단계 목차를 보인다.
  2. KPI 와 시계열 (1분) — EI·폭기 EI·FCR·OEI·폐사율. OEI 의 「잠정 지표」 배지와 산식 버전 표기를 짚는다.
  3. 전·후 비교와 A/B (1분) — 개선율이 지표 방향을 보정한 값임을, 대조군의 「산출 불가」가 0 으로 바뀌지 않음을 보인다.
  4. MRV 리포트 (1분) — 감축량, 산식 전문, 배출계수 출처, location/market-based 병기, residual mix 한계 문구.
  5. 보호 확인 (30초) — /mrv 로 가면 로그인 화면. 초대 계정으로 로그인하면 실제 16화면이 열린다(시간이 있으면 설정 → 사이트·수조·계측기 등록 → 입력 → 기준선 잠금 → 리포트 생성 흐름).
