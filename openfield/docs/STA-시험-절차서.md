## 2. 넣어야 할 것 (두 가지)

| 넣을 것 | 어디에 | 비고 |
|---|---|---|
| 고정 모델 묶음 `OFDF_시험대상_5ff054f.zip` | `model/` | zip 그대로 넣어도 되고, 풀어서 파일 56개를 넣어도 된다 |
| 데이터셋 캐시 `dataset.pkl` | `data/` | 학습 때 만든 파일 |

`dataset.pkl` 이 없으면 원천자료를 대신 넣는다. 그러면 `2_check` 가 캐시를 만든다(수 분).

- `data/aaos/` ← 구글 드라이브 「02. AI 노지 농업_대파 › 01. 기상데이터_나주_201601~202608」의 `기상 데이터_YYYYMM.xls` 전부
- `data/` ← 「260929_AI 노지 농업 기상 데이터_AgERA5」의 `AgERA5_Naju-Daegyo_2x2mean_daily_2015-2026.csv`

**모델은 보관본을 쓴다.** 학습했던 PC 의 `openfield/artifacts/weather/` 폴더(파일 56개)가 그것이다.

### 모델 묶음을 끝내 찾지 못했을 때

**`9_train_model`** 을 누른다(원천자료가 `data/` 에 있어야 한다. 수십 분 걸릴 수 있다).
같은 코드·같은 설정으로 다시 학습해 새 묶음을 `model/` 에 만들고, 그 묶음을 시험 대상으로 고정한다.

- 끝에 `모든 값이 성능평가서와 같습니다` 가 나오면 그대로 `2_check` 로 간다.
- `성능평가서와 다릅니다` 가 나오면 성능평가서를 새 값으로 다시 내야 한다. 화면 내용을 보관한다.
- `model/` 옆에 생긴 `OFDF_시험대상_5ff054f_<날짜>.zip` 을 **다른 곳에도 복사해 둔다.**
- 바뀐 `program/reports/시험의뢰/모델해시.md` 를 저장소에도 반영한다.
- 묶음이 이미 있으면 누르지 않는다. 다시 학습할 때마다 모델 파일이 달라진다.

## 3. 설치와 확인

파이썬 3.11 이상이 있어야 한다. GPU 는 필요 없다.

1. **`1_setup`** — 패키지를 깔고 프로그램이 제대로 도는지 스스로 시험한다. → **`24 passed`** 가 나와야 한다.
2. **`2_check`** — 넣은 모델과 자료를 확인한다. → **`모두 준비됐습니다`** 가 나와야 한다.
   빠진 것이 있으면 「남은 일」로 알려 준다. 채우고 다시 누른다.

모든 실행 파일은 끝에 `[exit code 0]` 이 나오면 성공이다. 0 이 아니면 다음으로 가지 않는다.

## 4. 본 시험

| 언제 | 누를 것 | 나와야 하는 것 |
|---|---|---|
| 전날(11-18) | **`3_rehearsal`** | `전 단계 통과` |
| 당일(11-19) 화면 공유 중 | **`4_test`** | `전 단계 통과` |

둘은 같은 일을 한다. 전날 것은 시험셋을 봉인해 두고, 당일 것은 그 봉인과 같은지 확인한다.

하는 일 (수 분, 자동으로 이어진다)

1. 판단 코드와 모델 56개 파일이 시험 대상 그대로인지 해시로 확인
2. 저장된 모델로 시험셋을 판정 — 학습은 하지 않는다
3. 데이터 한 건마다의 결과로 최종값을 다시 계산해 같은지 확인
4. 판단시간 200회 측정
5. 결과를 zip 으로 묶기

나오는 것

- **종합점수** — 판정 조치단위 Macro F1, 10개 판정 항목(위험유형 5종 × 1·3시간)
- **놓침 방지율** — 사례 단위. 시간 단위 재현율도 참고로 함께 나온다
- **판단시간** — 판단 1회 평균·중앙값·p95·최대
- 시점별·사례별 결과 CSV, 재계산 대조표, 모델·시험셋 sha256

전날 예행연습이 끝나면 `result/rehearsal_log.md` 를 연다. 시험 PC 사양(신청서 「시험환경」 칸),
단계별 소요시간, 항목별 결과가 적혀 있다.

## 6. 알아 둘 것

- 판정은 현장 제어기가 쓰는 코드(`program/src/ofdf`)를 그대로 불러 돌린다. 시험용으로 따로 만든 경로가 아니다.
- `3. 로그만으로 다시 계산` 은 CSV 두 개만 읽는다. 모델도 원천자료도 읽지 않는다.
- 놓침 방지율을 **시간 단위**로 판정하려면 `4_test --miss-unit hour` 로 실행한다. 기본은 사례 단위다.
- 위험사례가 30건 미만인 항목(강우·과습, 복합위험)은 결과에 그대로 표시된다. 빼거나 합치지 않는다.
- 명령을 하나씩 직접 치려면 `reference/STA-시험당일-실행순서` 를 본다.
