## A. 프로그램 설치

1. 시험 PC 에 **Python 3.11 이상**을 설치한다(`python --version` 으로 확인). 모델 학습 환경은 Python 3.13 / LightGBM 4.7.0 이다.
2. 프로그램을 둔다. 둘 중 하나.
   - 압축 묶음 `STA_AI노지_시험패키지.zip` 을 풀어 `openfield/` 폴더를 쓴다.
   - 또는 `git clone https://github.com/Ulrim/shrimp365` 뒤 `git checkout claude/sta-eval-logs`, `openfield/` 폴더를 쓴다.
3. `openfield/` 에서 `sta_0_setup` 을 실행한다. `.venv` 가상환경을 만들고 `requirements.txt` 의 패키지를 깐다.

## B. 자료 넣기

`openfield/` 아래 다음 위치에 둔다. 폴더가 없으면 만든다. **원본 자료는 저장소에 올리지 않는다.**

| 자료 | 어디서 | 넣을 위치 |
|---|---|---|
| 고정 모델 묶음 `OFDF_시험대상_5ff054f.zip` | 김정석 보관본 | 아무 곳(C 단계에서 경로를 알려 준다) — 풀리는 곳은 `artifacts/weather/` |
| 데이터셋 캐시 `dataset.pkl` (있으면) | 학습 때 만든 파일 | `artifacts/dataset.pkl` |

## C. 준비 점검

```
sta_1_prepare.bat --model-zip "C:\경로\OFDF_시험대상_5ff054f.zip"
./sta_1_prepare.sh --model-zip ~/Downloads/OFDF_시험대상_5ff054f.zip
```

모델을 이미 `artifacts/weather/` 에 풀어 두었으면 `--model-zip` 없이 실행한다. 다섯 가지를 확인한다.

| # | 확인 | 준비됨 표시 |
|---|---|---|
| 1 | 실행 환경 | Python·패키지 버전 |
| 2 | 판단 코드 | `src/ofdf` 가 시험 대상 커밋과 같다(해시 목록 대조, git 이 있으면 git 비교도) |
| 3 | 원천자료 | AAOS 파일 수·기간, AgERA5 파일 |

| 5 | 고정 모델 묶음 | 56개 파일 sha256 이 `reports/시험의뢰/모델해시.md` 와 일치 |

## D. 예행연습 (11-18)

```
sta_2_rehearsal.bat        또는    ./sta_2_rehearsal.sh
```

당일과 같은 순서를 끝까지 돌린다. 하나라도 실패하면 그 단계에서 멈춘다.

| 순서 | 하는 일 | 통과 기준 |
|---|---|---|
| 1 | 코드 확인 (`git diff 5ff054f -- src/ofdf`, git 저장소일 때) | 출력 없음 |
| 2 | 코드·모델 해시 확인 | 56개 「일치」 |
| 3 | 고정 모델 평가 → 시점별·사례별 CSV, 최종결과 JSON | `[대조] performance.csv … 모두 일치` |
| 4 | 로그만으로 재계산 | `[일치] N개 값이 모두 최종결과와 같습니다` |
| 5 | 판단시간 200회 측정 | 평균 30초 이내 → 적합 |
| 6 | 재계산(판단시간 포함) | `[일치]` |
| 7 | 결과 묶음 압축 | zip 생성 |

끝나면 자동으로

- 결과 묶음 `sta_ai노지_예행/` 과 `sta_ai노지_예행_<날짜>.zip` 이 생기고,
- **시험셋 sha256 을 `artifacts/sta_봉인_시험셋.sha256` 에 적는다**(당일에 이 값과 대조한다),
- `reports/시험의뢰/STA평가_사전실행로그.md` 에 실행 환경·단계별 소요시간·항목별 결과가 남는다.

예행연습 뒤 할 일

1. 사전실행로그의 「실행 환경」 표를 시험신청서 「시험환경」 칸(OS·CPU·RAM·HDD)에 옮겨 적는다.
2. 총 소요시간이 30분 이내인지 본다.
3. 항목별 결과가 성능평가서와 같은지(종합점수 10/10, 사례 단위 놓침 방지율 10/10) 본다.
4. 3단계가 `[실패] performance.csv 와 다릅니다` 로 멈추면 — 캐시가 학습 때 것과 같은 자료인지, LightGBM 버전이 4.7.0 인지 확인한다.

## 멈췄을 때

| 메시지 | 뜻 | 할 일 |
|---|---|---|
| `[중단] 모델 묶음이 해시 목록과 다릅니다` | 모델이 보관본과 다르다 | 보관한 zip 으로 C 단계를 다시. **다시 학습하지 않는다** |
