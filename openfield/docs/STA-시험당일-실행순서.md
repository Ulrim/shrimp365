## 3. 고정 모델 평가 (2분 안팎)

```bash
python scripts/sta_evaluate.py \
  --cache artifacts/dataset.pkl \
  --models artifacts/weather \
  --out sta_ai노지 \
  --seed 42 \
  --expect-testset-sha256 <전날 적어 둔 시험셋.csv sha256>
```

- 학습은 하지 않는다. 저장된 모델로 시험셋의 각 시각을 판정한다.
- 화면에 항목별 결과표(표본·위험 표본·사례 수, 판정 조치단위 F1, 사례 단위 놓침 방지율, 시간 단위 재현율)가 나온다.
- 마지막 줄 `[대조] performance.csv … 모두 일치` — 성능평가서 수치와 소수 셋째 자리까지 같다는 뜻이다.
- 종료 코드 : 0 정상 / 1 성능평가서와 다름 / 2 시험 대상(코드·모델·시험셋)이 다름.

놓침 방지율 판정 셈법은 설정값이다. 기본은 사례 단위(`--miss-unit case`)이고,
시간 단위로 판정하려면 `--miss-unit hour` 를 준다. 어느 쪽이든 세 값이 모두 로그에 남는다.

## 4. 로그만으로 다시 계산 (1분)

```bash
python scripts/sta_recompute.py --dir sta_ai노지
```

- `02_시점별_결과.csv`, `02_사례별_결과.csv` 만 읽는다(모델·원천자료를 읽지 않는다. 표준 라이브러리만 쓴다).
- 항목마다 혼동행렬 → 등급별 정밀도·재현율·F1 → Macro F1, 사례 단위 놓침 방지율, 시간 단위 재현율을
  다시 계산해 `03_최종결과.json` 과 견준 표를 보여 준다.
- 마지막 줄 `[일치] N개 값이 모두 최종결과와 같습니다`, 종료 코드 0.

설명할 것(스크립트 맨 위 주석에 같은 식이 있다)

| 값 | 계산 |
|---|---|
| 혼동행렬 | `정답_평가단위` × `예측_평가단위` 줄 수 |
| 등급별 F1 | 2·TP / (2·TP + FP + FN) |
| 종합점수(Macro F1) | 등급별 F1 의 단순 평균 (3등급 유형은 3개, 2등급 유형은 2개) |
| 놓침 방지율(사례 단위) | `위험사례ID` 가 같은 줄을 한 사례로 묶어, 예측등급 ≥ 1 이 한 번이라도 있는 사례 수 / 사례 수 |
| 시간 단위 재현율(참고) | 정답등급 ≥ 1 인 줄 가운데 예측등급 ≥ 1 인 줄의 비율 |

## 5. 판단시간 200회 측정 (1분)

```bash

  --cache artifacts/dataset.pkl --models artifacts/weather \
```

- 판정 대상은 `끝에서 끝까지(ms)` 의 평균, 기준 30초(30,000ms) 이내.

## 열 설명

`02_시점별_결과.csv`

| 열 | 뜻 |
|---|---|
| 판정항목 · 위험유형 · 시계(h) | 예: 저온·서리 3시간 |
| 시각 · 관측지점 | 판정한 시각(이 시각까지의 관측으로 앞으로 `시계` 시간 안의 최고 등급을 맞힌다) |
| 평가단위 | 3등급(정상·주의·경계) 또는 2등급(정상·위험 — 주의와 경계의 조치가 같은 유형) |
| 정답등급 · 예측등급 | 0 정상 / 1 주의 / 2 경계 |
| 정답_평가단위 · 예측_평가단위 | 2등급 유형은 주의·경계를 1(위험)로 합친 값. 종합점수는 이 두 열로 계산한다 |
| 일치(0/1) | 두 평가단위 값이 같으면 1 |
| 위험사례ID | 그 시각이 속한 위험사례. 위험이 걸려 있지 않은 시각은 빈칸 |
| 확률_정상 · 주의 · 경계 | 3등급 모델이 낸 등급별 확률(판정 가중치 적용 전). 복합위험은 따로 학습한 모델이 없어 빈칸 |
| 판정점수 · 판정경계 | 위험 여부를 정한 값과 그 경계 — 2등급 유형은 전용학습 앙상블의 P(위험), 복합위험은 P(과습) × max(P(병해), P(서리)) |
