## 4. 시험 당일 설명 요지 (항목별 1분)

1. **시험 대상 고정** — 판단 코드는 커밋 `5ff054f` 그대로(`git diff` 빈 출력), 모델·경계 파일 56개는 해시 목록과 일치, 시험셋은 전날 봉인한 sha256 과 일치.
2. **데이터별 결과** — `02_시점별_결과.csv` 는 시험셋의 한 시각 × 판정 항목 1개가 한 줄이다. 정답등급과 예측등급이 건마다 있다.
3. **종합점수** — 항목마다 `정답_평가단위` × `예측_평가단위` 로 혼동행렬을 만들고, 등급별 F1 = 2·TP / (2·TP + FP + FN), 그 단순 평균이 Macro F1 이다.
4. **놓침 방지율** — `위험사례ID` 가 같은 줄을 한 사례로 묶어, 예측등급 ≥ 1 이 한 번이라도 있으면 탐지. 탐지 사례 수 / 사례 수.
5. **재계산** — `sta_recompute.py` 는 위 두 CSV 만 읽어 같은 식으로 다시 계산하고 `03_최종결과.json` 과 한 값씩 견준다. 모두 일치하면 종료 코드 0.
6. **판단시간** — 판단 1회(피처 생성 → 추론 → 판단근거 → 조치 결정 → 이력 기록)를 200회 재고, 회차별 값의 평균이 30초 이내인지 본다.
7. **숨기지 않는 것** — 시간 단위 재현율(참고)과 사례 30건 미만 항목은 결과표·통계에 그대로 표시된다.
