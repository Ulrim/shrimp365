## 3. 의뢰 전에 정해야 할 것

시험기관에 접수하기 전에 발주기관(전남정보문화산업진흥원)·시험기관과 확정한다.

### 3-1. 놓침 방지율의 셈법 (A-1)

계획서 9쪽은 '주의·경계 위험 100건 중 85건 이상을 놓치지 않는', **'독립 이벤트 단위로
산출'** 이라고 적고, 24쪽은 **'사례별 탐지 여부·사전 알림시간'** 으로 적는다. 이에 따라
성능평가서는 사례 단위로 판정한다. 다만 아래를 함께 알려야 한다.

- 사례 단위 탐지는 위험이 **시작된 뒤**의 경보도 탐지로 센다. 단순 규칙도 100% 다.
- 시간 단위 재현율로는 10개 중 6개만 85% 이상이다(강우·과습 0.777 / 0.632, 복합 0.836 / 0.592).
- 강우·과습의 시작 전 탐지율은 1시간 0.190, 3시간 0.524 다.
- 시험 사례 수가 적다 — 강우·과습 21건, 복합위험 18건. 계획서 16쪽은 '시험 이벤트가
  10건 미만인 위험유형은 현장 입력모사 결과를 별도 표기'라고 한다(둘 다 10건 이상).

**정할 것** — 사례 단위로 판정할지, 시간 단위로 판정할지. 성적서에 어느 값을 싣는지.

### 3-2. '5%p 이상 개선'의 기준 지표 (B-1)

계획서는 무엇으로 재는지 명시하지 않는다. 종합점수로 재면 6/10, 시간 단위 재현율로
재면 9/10, 사례 단위 놓침 방지율로는 규칙이 100% 라 비교할 수 없다.
24쪽은 '규칙 기반 대비 선행시간·오경보율'도 비교 대상으로 적는다.

### 3-3. 계획서와 구현이 다른 곳 — 시험 전에 설명 자료가 필요하다

| 항목 | 계획서 (5차) | 현재 구현·평가 | 조치 |
|---|---|---|---|
| 공공 기상 자료 | 나주·순천·고흥·진도 **ASOS·AWS 4지점** 105,120건(최근 3년) | **농업기상관측(AAOS) 나주 5지점**, 2016~2025, 437,179시간 | 자료 출처 변경 사유를 문서화 |
| 현장 실측 | 적용·비교구간 각 12,000시점 이상으로 농지별 보정·현장 시험셋 구성 | 성능평가는 **공공 관측자료만** 사용. 현장 실측 반영 여부 미확인 | 현장 자료로 보정·검증 결과 추가 (§4-2) |
| 예보 입력 | 기상청 예보 + 농지센서 | 예보 입력 **없음**(관측값만). 저온·서리 라벨의 '예보 최저기온'도 관측 기반 대리지표 | 한계로 명시. 기상청 API 키 확보 시 연계 |

| 시험 대상 위험유형 | 고온·건조, 강우·과습, 저온·서리, 병해 유리환경, 복합위험 | 같음 (5종 × 1·3시간 = 10항목) | — |

## 6. 시험기관에 미리 알릴 한계

성능평가서와 모델 설명서에 이미 적혀 있다. 접수 때 구두로도 알린다.

1. 기상 위험판단 성능은 **과거 공공 관측자료**로 잰 값이다. 실증지 현장 센서 자료가 아니다.
2. 평가 분할은 지점 구분 없이 시각 단위다. 같은 비가 여러 지점에 동시에 내리므로 이렇게
   나눠야 학습·시험이 겹치지 않는다. 이전 판(10-11, 11-10)의 강우·과습 수치는 부풀려져 있었다.
3. 강우·과습·복합위험은 **큰비의 시작을 미리 알리는 힘이 약하다.** 예보 입력이 없기 때문이다.
4. 판정 경계의 선택 규칙과 놓침 방지율 셈법은 결과를 본 뒤에 바꾼 이력이 있다(성능평가서 §1).
5. 시나리오 시험은 현재 **입력모사**다.
6. 비전 병해 진단(F1 0.825 / 0.543)은 계획서에서 '병 진단은 범위 제외'라 시험 대상이 아니다.
