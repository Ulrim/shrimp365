## 1. 설치 (10분)

파이썬 **3.11 이상**이 있어야 한다(`python --version`). GPU·torch 는 필요 없다.

**윈도우 (PowerShell)**

```powershell
cd 프로그램
py -3 -m venv .venv
.venv\Scripts\python -m pip install -r requirements-sta.txt
```

**맥·리눅스**

```bash
cd 프로그램
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-sta.txt
```

아래부터는 파이썬을 `PY` 로 줄여 적는다 — 윈도우는 `.venv\Scripts\python`, 맥·리눅스는 `.venv/bin/python` 이다.
모든 명령은 **`프로그램/` 폴더에서** 친다.

설치 확인(선택): `PY -m pytest tests/test_eval_detect.py -q --noconftest` → `46 passed`

### 5-3. 시험원에게 설명할 내용 — 데이터별 결과에서 최종값이 나오는 길

묶음의 `README_읽는법.txt` 와 CSV 를 열어 보이며 설명한다.

| 최종값 | 어느 로그에서 | 어떻게 |
|---|---|---|
| 정답 총수 N | `02_정답별_결과.csv` | 줄 수 (3,699) |
| mAP@0.5 | `02_예측별_결과.csv` | 모든 이미지의 예측을 `전체순위`(신뢰도 내림차순)로 세우고, `TP@0.50` 열로 누적 TP·FP → 정밀도·재현율 곡선 → 101점 보간 평균 |
| mAP@0.5:0.95 | 같은 파일 | `TP@0.50` … `TP@0.95` 열 10개로 같은 계산을 해 평균 |
| Precision·Recall·F1 | 두 파일 | TP = 정답별 로그에서 `운영임계값에서_탐지`=1 인 줄 수, FP = 예측별 로그에서 `운영임계값_이상`=1 인 줄 수 − TP, FN = N − TP |
| 계수 오차율 | 두 파일 | 이미지마다 검출 수(`운영임계값_이상`=1 인 예측 수)와 정답 수(정답 줄 수)로 \|검출−정답\|÷정답 → 평균·중앙값·최대·±20% 이내 비율 |

- **mAP@0.5 는 이미지별 AP 의 평균이 아니다.** `02_이미지별_결과.csv` 의 `AP@0.5(이미지 단독)` 은 참고값이다(정답 0마리 이미지는 빈칸).
- 재계산 프로그램은 모델·이미지를 읽지 않고 CSV 만 읽는다. 식은 `recompute_detect.py` 머리말에 번호를 붙여 적었다.
- 예측과 정답의 짝짓기(IoU 매칭)는 다시 하지 않는다. 로그의 TP(0/1) 열에서 출발해 그 뒤 집계를 모두 다시 한다.
- 판정은 `03_최종결과.json` 에 적힌 값(소수 넷째 자리 반올림)을 기준과 견준다.

## 판정 기준은 설정값이다

기본값은 시험신청서와 같다. 바꿀 때는 `sta_run.py` 명령 끝에 `--` 를 붙이고 적는다.

```
PY ai/trainer/sta_run.py rerun -- --count-judge both --pass-count-within 0.8
```

| 인자 | 기본값 | 뜻 |
|---|---|---|
| `--pass-map50` | 0.75 | mAP@0.5 가 이 값 이상이면 적합 |
| `--count-judge` | `mean` | 계수 오차율 판정 방식: `mean`(이미지별 오차율 평균) · `within`(±20% 이내 비율) · `both` |
| `--pass-count-mean` | 0.20 | 평균 오차율이 이 값 이하면 적합 |
| `--pass-count-within` | 없음 | ±20% 이내 비율이 이 값 이상이면 적합(`within`·`both` 일 때 반드시 지정) |
| `--count-tolerance` | 0.20 | 「이내」로 볼 허용오차 |

측정값은 판정 기준과 무관하게 모두 기록된다. 사전 측정과 당일 실행에 **같은 인자**를 쓴다.
