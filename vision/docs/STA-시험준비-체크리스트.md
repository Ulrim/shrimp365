## 3. 시험신청서 초안에서 고칠 문안

신청서 파일은 손대지 않았다. 아래는 결과물과 맞추기 위한 **제안 문안**이다.

| 위치 | 지금 문구 | 바꿀 문구 | 이유 |
|---|---|---|---|
| 항목 1 · 시험절차 3 | 이미지별 결과(정답 수·검출 수·TP·FP·FN·AP)를 CSV로, 최종 결과(모델 sha256 포함)를 JSON으로 출력해 log로 확인 | **예측 박스별·정답 박스별·이미지별 결과를 각각 CSV로**, 최종 결과(모델·시험 데이터·코드 sha256 포함)를 JSON으로 출력해 log로 확인 | 로그가 3종이다 |
| 항목 1 · 시험절차 4 | 이미지별 결과로 최종 mAP@0.5 계산 과정을 설명 | **예측 박스별 결과(신뢰도·TP 여부)와 정답 박스 수로 최종 mAP@0.5 를 다시 계산해**(재계산 프로그램 recompute_detect.py) **최종값과 일치함을 확인하고 계산 과정을 설명** | mAP 는 이미지별 AP 의 평균이 아니라 예측 전체를 합쳐 계산한다 |
| 항목 1 · 시험절차 2 | 측정 프로그램 실행(신뢰도 임계값 0.25, IoU 0.5, COCO 101점 보간) | 측정 프로그램 실행(**운영** 신뢰도 임계값 0.25, **매칭** IoU 0.5, **NMS IoU 0.7, mAP 곡선용 최저 신뢰도 0.001,** COCO 101점 보간) | 실제 실행 조건을 빠짐없이 |
| 항목 1·2 · 시험도구 | …측정 프로그램(eval_detect.py), 시험 이미지·라벨 | …측정 프로그램(eval_detect.py), **재계산 프로그램(recompute_detect.py),** 시험 이미지·라벨 | 도구가 하나 늘었다 |
| 항목 2 · 시험절차 3 | 이미지별 값으로 평균 오차율을 다시 계산해 최종값과 일치함을 설명 | **이미지별 검출 수·정답 수로** 평균 오차율을 다시 계산해 최종값과 일치함을 **확인하고** 설명 | (작은 다듬기) |
| 기타 참고사항 · 둘째 줄 | 데이터별 결과: 이미지별 결과(CSV)와 최종 결과(JSON)를 함께 제출 | 데이터별 결과: **예측 박스별·정답 박스별·이미지별 결과(CSV 3종)**와 최종 결과(JSON), **재계산 결과**를 함께 제출 | 위와 같음 |
| 시험환경구성도 | 측정 프로그램(eval_detect) 실행 → 데이터별 결과 로그(CSV)·최종 결과(JSON) 생성 | 측정 프로그램(eval_detect) 실행 → 데이터별 결과 로그(CSV)·최종 결과(JSON) 생성 **→ 재계산 프로그램(recompute_detect)으로 로그만 읽어 최종값 재계산·대조** | 위와 같음 |
| 시험환경 · 소프트웨어 | Python 3.11, numpy, onnxruntime, pillow, pydantic, … | Python **【시험 PC의 실제 버전】**, numpy, onnxruntime, pillow, pydantic, **pydantic-settings**, … | 빠진 패키지 1개. 버전은 실제 값으로(3.11 이상이면 된다) |
| 시험환경 · OS/CPU/RAM/HDD | 【확인】 | `03_최종결과.json` 의 `실행_환경` 값 | 사전 측정 뒤에 채운다 |

계수 오차율 기준(항목 2)을 「±20% 이내 비율」로도 판정하기로 하면, 시험기준·예상결과 문구와
실행 인자(`sta_run.py … -- --count-judge both --pass-count-within <비율>`)를 함께 바꾼다.
