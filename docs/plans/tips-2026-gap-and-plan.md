아이템명: 양식장 수익성 향상을 위한 AI 기반 운영분석 및 출하의사결정 지원 서비스 (㈜컬리버)

## 0. 결론 먼저

**"개발된 것이 없다"가 아니다. 전제를 정정한다.**

| 구분 | 상태 |
|---|---|
| 웹 플랫폼 (클라우드 서버 + 애플리케이션 계층) | **상당 수준 구현** — 화면 29개, Supabase 마이그레이션 85개, 생산관리·수익분석 탭 가동 |
| 엣지 장비 (센서 노드 계층) | **상당 수준 구현** — `raspberry-pi/` 24개 파일, 수집·판정·권고·경보·OTA·버퍼링까지 현장 동작 |
| 비전 기반 급이 최적화 | **전무** — 코드 0줄, 사업비 4,500천원이 배정된 항목 |
| 수익성 **예측** 엔진 (성장곡선·예상이익·출하윈도우) | **미구현** — 현재 지표는 전부 수확 완료 후 사후 집계 |
| 통신 아키텍처 (MQTT·게이트웨이 계층·시계열 파티셔닝) | **미구현** — 계획서 4계층 중 2계층이 독립 컴포넌트로 존재하지 않음 |
| 다국어 리포트 엔진 | **미구현** — UI 번역 사전(ko/en/vi/id)은 있으나 리포트 생성 엔진 없음, **태국어 미지원** |

한 줄로 줄이면 — **"보여줄 화면과 현장 장비는 있고, 이 사업의 아이템명에 적힌 두 단어(`AI 기반 운영분석`의 예측 부분과 `출하의사결정`)가 아직 비어 있다."**

그리고 코드와 별개로 더 급한 문제가 있다. **계획서와 코드가 어긋난 지점 세 군데**(측정 주기, 암모니아 센서, 유료화 비활성)는 점검위원이 계획서를 펼쳐 놓고 대조하면 즉시 드러난다. 6절에 따로 뺐다.

### 3단계 — 비전 모듈 및 하이브리드 데이터 수집 (26.05~26.06) · `❌`

| 계획서 | 저장소 현황 |
|---|---|
| CCTV 비전 모듈 + 수중 조명 | **없음** |
| YOLO 등 객체탐지로 활동량·사료 반응성·개체 크기 분석 | **코드 0줄.** `yolo\|opencv\|picamera\|camera` 전체 검색 결과는 3D 뷰어(`components/farm3d/`)의 three.js 카메라뿐 |
| 수질 변수와 교차검증, 사료 효율 5~10% 개선 | 근거 코드 없음 |
| 엣지에서 영상→특징 데이터 추출 | 없음 |

**사업비가 배정된 항목이다** — 카메라 모듈+수중조명 5식 3,500천원 + 데이터 라벨링·비전 알고리즘 보조 1,000천원. 동시에 "사료 효율 5~10% 개선"이라는 정량목표와 경쟁사(eFishery) 대비 차별점의 근거다. 7단계 중 유일한 완전 미착수 구간이며, 가장 변명이 어려운 칸이다.

## 5. 우선순위 권고 — 4개월에 12건을 다 할 수 없다

### 반드시 한다 (S·A)

| 항목 | 판단 |

### 하지 말 것

- **이미 있는 것을 다시 만들지 말 것.** 엣지 이상탐지(`anomaly.py`), 운전 권고(`advice.py`), 버퍼링(`buffer.py`), 생산관리 테이블(`production_management.sql`), 사후 수익 집계(`production/page.tsx`), i18n 라우팅(`lib/i18n/`)은 구현되어 있다. 2차 작업은 `production/page.tsx`의 기존 `costPerKg`·`profit`·`roi`·`fcr` **위에 예측을 올리는 것**이고, 4차 작업은 `lib/i18n/`을 **버리는 것이 아니라 리포트 경로를 그 위에 붙이는 것**이다.
- 라우팅·캐싱·서버 액션 설계를 기억으로 쓰지 말 것. 이 저장소는 **Next.js 16.2.4**다. 착수 전 `node_modules/next/dist/docs/`의 해당 가이드를 읽는다.

| 항목 | 내용 |

| 산출물 「모바일 어플리케이션 1개」 | PWA(`app/manifest.ts`)로 충족할지, 스토어 등록까지 갈지 **사람이 정해야 한다.** 계획서에 형태 명시가 없다 |
| 4계층 중 2계층 | 계획서는 **데이터 게이트웨이 계층**을 독립 계층으로 그렸는데 구현은 노드가 겸한다. 구조도를 제출하면 바로 보이는 차이다. 5-2로 구현하거나, 구조도 주석에 "노드 내장형 게이트웨이"로 명기해 일치시킨다 |

## 7. 사람이 해야 하는 일 — 에이전트가 못 한다

| # | 항목 | 비고 |
|---|---|---|
| 1 | **실증 양식장 섭외·현장 설치** | 7단계의 전제. 실증고객 2~3개소가 매출 목표의 근거다. `install.sh`·`setup-kiosk.sh`로 설치 자동화는 준비되어 있으나 물리적 설치는 사람 몫 |

| 3 | **홍보 동영상 1개 제작** | 협약기간 내 산출물. 저장소 밖 작업 |

| 5 | **Supabase SQL 실행** | DB 쓰기에는 service_role 키가 필요하고 이 저장소에 그 키는 없다. 마이그레이션 커밋까지가 에이전트의 일이고 **실행은 사람이 SQL Editor에서 한다** |

| 7 | **실증 현장 사진·시험 기록 촬영** | 점검 증빙은 실제 촬영본만 쓴다 |
