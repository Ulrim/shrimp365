# 새우 라벨링 기준 — 한 장

`vision/` 개체탐지용 · 2026-11-12 · 클래스는 **`shrimp` 하나**
작업 전에 끝까지 한 번 읽고, 작업 중에는 띄워 두십시오.

> **한 줄 원칙 — "물속에 살아 있는 새우 한 마리의 몸통."**
> 망설여지면 아래 표를 보고, 표에 없으면 §4 로 갑니다. **혼자 판단해서 새 규칙을
> 만들지 마십시오.** 사람마다 다르게 그리면 성능 수치가 그만큼 흔들립니다.

---

## 1. 그린다 / 안 그린다

| | 대상 | 어떻게 |
|---|---|---|
| ✅ | 온전히 보이는 새우 | 그린다 |
| ✅ | 다른 새우·급이대에 가려진 새우 — **몸통이 절반 이상** 보임 | 보이는 부분만 감싼다 |
| ✅ | 화면 가장자리에 걸친 새우 — 몸통이 절반 이상 보임 | 보이는 부분만 감싼다 |
| ✅ | 겹쳐 있는 새우들 | **한 마리씩 따로.** 상자끼리 겹쳐도 된다 |
| ✅ | 흔들려 번진 새우 — 새우인 줄 알아볼 수 있음 | 그린다 |
| ✅ | 죽은 것으로 보이는 새우 (몸통·눈이 남아 있음) | 그린다 |
| ❌ | 몸통이 절반 미만만 보이는 새우 | 그리지 않는다 |
| ❌ | **수면에 비친 상** | 그리지 않는다 |
| ❌ | **탈피각** (속이 빈 투명 껍질, 눈·색 없음) | 그리지 않는다 |
| ❌ | **사료 입자, 기포, 그물코, 침전물** | 그리지 않는다 |
| ❌ | 너무 작거나 흐려 새우인지 알 수 없는 것 | **찍지 않는다.** 추측 금지 |

마지막 두 줄이 중요합니다. 사료와 기포는 **헛검출의 가장 큰 원인**이라, 여기에
상자를 치면 모델에게 "이것도 새우다"라고 가르치는 셈이 됩니다.

---

## 2. 상자 범위

1. **몸통만** — 두흉부(머리가슴)부터 꼬리 끝까지.
2. **더듬이·다리·꼬리털은 뺀다.** 포함하면 상자가 사람마다 크게 달라지고, 정확도
   지표(IoU)가 그만큼 흔들립니다.
3. **딱 맞게.** 여백을 두지 않고, 몸통을 자르지도 않습니다.

```
   ┌──────────────┐        ← 꼬리 끝
   │   몸통만     │
   └──────────────┘        ← 머리 앞(더듬이 시작점)
     ~~~~ 더듬이는 상자 밖 ~~~~
```

---

## 3. 빈 화면도 자료입니다

새우가 한 마리도 없는 프레임은 **지우지 말고 상자 0개로 제출**하십시오.
"빈 수조에서 헛검출이 몇 개 나오는가"는 이 프레임으로만 잴 수 있습니다.

---

## 4. 헷갈리면

1. 상자를 치지 말고 **그 파일 이름을 「보류」 목록에 적습니다.**
2. 하루 작업이 끝나면 보류 목록을 모아 **함께 봅니다.**
3. 결론이 나면 **이 문서에 한 줄 추가**하고, 그 규칙으로 **앞서 작업한 것도 다시
   확인**합니다.

작업 중간에 기준을 바꾸면 앞뒤 자료가 서로 다른 기준으로 섞여, 나중에 어느 쪽이
맞는지 알 수 없게 됩니다.

---

## 5. 작업 전후 점검

**시작 전**
- 클래스 이름이 `shrimp` 하나인지 (대소문자까지 동일)
- 첫 20장은 **두 사람이 같은 장을** 따로 작업해 서로 비교 — 개체 수가 10% 넘게
  다르면 기준 해석이 갈린 것이므로, 맞춘 뒤에 본작업을 시작합니다.

**끝난 뒤**
- 전체의 10~20%는 **밑그림 없이 백지에서** 작업한 것으로 남깁니다.
  밑그림(사전 라벨)을 고치는 방식은 빠르지만, 사람은 **있는 상자를 지우는 일**은
  잘 해도 **없는 상자를 새로 그리는 일**은 잘 하지 않습니다. 그러면 모델이 놓친
  새우가 정답에서도 빠져, 성능이 실제보다 좋게 나옵니다.
  두 방식의 **평균 개체 수가 크게 다르면** 고치는 방식이 놓치고 있다는 뜻입니다.

이 상자들이 **공인 시험성적서의 정답**이 됩니다. 기준이 흔들리면 모델이 아니라
자료가 틀린 것이고, 그건 나중에 재계산해서야 드러납니다.
