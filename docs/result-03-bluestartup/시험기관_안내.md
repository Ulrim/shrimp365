## 2. 설치 (노트북 한 대면 됩니다)

GPU 도 torch 도 필요 없습니다.

```
cd 프로그램
python -m venv .venv
. .venv/bin/activate          # 윈도우: .venv\Scripts\activate
pip install numpy onnxruntime pillow pydantic pydantic-settings
```

파이썬 3.11 이상이면 됩니다.

---

## 3. 설치가 제대로 됐는지 확인

받은 그대로 아래를 돌리면, 프로그램이 도는지와 지표 계산이 맞는지를 한 번에
볼 수 있습니다.

```
cd 프로그램
python -m pytest tests/test_eval_detect.py -q --noconftest
```

→ **34건 통과**가 나와야 합니다. 이 시험들은 추론을 쓰지 않고, 손으로 답을 알
수 있는 경우(IoU 반 겹침 = 1/3, 재현율 0.5 에서 끊긴 AP = 51/101 등)로 지표
계산만 검증합니다.

이어서 예제 15장으로 측정이 도는지 봅니다.

```
python ai/trainer/eval_detect.py \
  --weights ../모델/shrimp_yolov8n_416.onnx \
  --images ../예제_15장/images --labels ../예제_15장/labels \
  --conf 0.25 --bootstrap 2000
```

→ mAP@0.5 1.0000 이 나옵니다. **이 값은 성적이 아닙니다** — 15장짜리 설치
확인용입니다.

## 4. 본 시험

시험 이미지를 받으시면 같은 명령에 경로만 바꿔 주십시오.

```
python ai/trainer/eval_detect.py \
  --weights ../모델/shrimp_yolov8n_416.onnx \
  --images <받으신>/test/images --labels <받으신>/test/labels \
  --conf 0.25 --bootstrap 2000 \
  --json 결과.json --csv 이미지별.csv
```

나오는 것

* **mAP@0.5**, mAP@0.5:0.95 (IoU 0.50\~0.95, 0.05 간격, COCO 101점 보간)
* 운영 임계값(0.25)에서의 **Precision · Recall · F1**
* **계수 오차율** — 평균·중앙값·최대, ±20% 이내 비율
* 탐지율 95% 하한 (이항분포, 표본이 작을 때의 정직한 상한선)
* 이미지별 결과 CSV

`결과.json` 에는 **측정 당시 읽은 모델의 sha256** 이 함께 적힙니다. 성적서의
수치와 모델 파일이 어긋날 수 없게 하려는 것입니다.

틀린 장면을 눈으로 보시려면:

```
python ai/trainer/draw_detections.py \
  --weights ../모델/shrimp_yolov8n_416.onnx \
  --images <받으신>/test/images --labels <받으신>/test/labels --out 그림
```

초록이 정답, 빨강이 예측입니다.

빼 주십시오** — 모델 적재 시간이 섞입니다.

## 6. 알아 두실 것

* 추론은 현장 장비가 쓰는 코드(`app/services/detector_onnx.py`)를 그대로
  불러 돌립니다. 전처리(letterbox)·NMS·좌표 복원이 모두 **실제로 출하되는
  경로**와 같습니다. 시험용으로 따로 만든 경로가 아닙니다.
* 라벨은 YOLO 형식이며 **박스와 폴리곤을 모두** 받습니다. 폴리곤은 외접
  박스로 접습니다. 원본 데이터셋이 폴리곤이라 그대로 보내 드립니다.
* 라벨 파일은 이미지와 **파일 이름이 같아야** 합니다(확장자만 `.txt`).
* 정답 상자를 **어떤 기준으로 그렸는지**는 `참고/라벨링_기준` 에 있습니다.
  더듬이·다리를 상자에서 뺐고, 가려진 개체는 몸통이 절반 이상 보일 때만
  그렸으며, 수면 반사·탈피각·사료 입자는 그리지 않았습니다. 지표를 해석하실
  때 이 기준을 함께 보셔야 합니다.
* `참고/수조데이터_확보계획` 은 현장 수조 데이터를 모으는 계획입니다. 이번
  시험 대상은 아니지만, 공개 데이터셋과 실제 운용 조건이 어떻게 다른지를
  적어 두었습니다.
* `참고/03_결과보고서_자료집` 은 시스템 구성·웹 화면·현장 장비 화면을 그림
  13장으로 정리한 것입니다. 시험 대상 모델이 **어떤 장치 안에서** 도는지
  보시는 데 도움이 됩니다. PDF 와 한글 파일 둘 다 들어 있습니다.
