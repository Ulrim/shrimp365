# AI 노지 시험 항목 3(AI 판단 시간) 확인사항 회신

주식회사 컬리버 · 2026-11-22 · 수신: STA테스팅컨설팅 김정아 님

확인해 주신 세 가지가 모두 맞습니다. 제출한 설명서의 문구가 실제 측정과 달랐습니다. 아래와 같이 바로잡고, 시험 데이터 22,740건 전체에 대해 건마다 시작·종료 시각을 남기는 방식으로 다시 측정하고자 합니다.

## 1. 단계 합계와 「끝에서 끝까지(ms)」가 다른 이유

계산해 주신 값이 맞습니다. `06_판단시간_회차별.csv` 의 여섯 열은 한 번의 실행을 나눠 잰 것이 아니라, **열마다 따로 200회씩 반복해 잰 값**입니다. 같은 줄의 값들은 같은 실행에서 나온 것이 아니므로 더해도 「끝에서 끝까지」가 되지 않습니다.

또 「끝에서 끝까지」 측정에 들어간 범위가 단계별 측정과 달랐습니다.

| 구분 | 단계별 열 | 「끝에서 끝까지」 열 |
|---|---|---|
| 입력 변수 계산 | 포함 | 포함 |
| 모델 추론 | 1시간·3시간 모델 38개 | **3시간 모델 19개만** |
| 판단근거 추출 | 포함 | 포함 |
| 조치 결정 | 포함 | 포함 |
| 이력 기록 | 포함 | **포함하지 않음** |

| 값 (200회 평균) | ms |
|---|---|
| 피처 생성 | 9.910 |
| 모델 추론 (38개) | 30.993 |
| 판단근거 | 4.180 |
| 조치 결정 | 0.019 |
| 이력 기록 | 0.427 |
| **다섯 단계의 합** | **45.529** |
| 끝에서 끝까지 | 29.990 |

설명서의 「① 입력 변수 계산 ② 모델 추론(38개 모델) ③ 판단근거 추출 ④ 조치 결정 ⑤ 이력 기록까지 … 이 전체를 끝에서 끝까지로 잰다」는 문장은 사실과 다릅니다. 「끝에서 끝까지」 값(29.99 ms)에는 1시간 모델 19개의 추론과 이력 기록이 들어 있지 않습니다. 설명서를 잘못 작성했습니다.

다섯 단계를 모두 더한 값(45.53 ms)으로 보아도 기준(평균 30초 = 30,000 ms 이내)과의 차이는 큽니다. 다만 이 값도 아래 2·3번의 요건을 갖추지 못했습니다.

## 2. 시작·종료 시각 기록

**없습니다.** 시험 당일 측정 프로그램은 회차마다 소요시간(ms)만 기록했고 시작·종료 시각은 남기지 않았습니다. 화면 녹화에도 회차별 시각은 나오지 않습니다.

## 3. 측정에 쓴 데이터

시험 데이터 22,740건으로 측정한 것이 **아닙니다.** 시험 중 그렇게 말씀드린 것은 잘못된 설명이었습니다. 실제로는 다음과 같습니다.

- 입력 1건(전체 데이터셋 109,200건의 가운데 위치 한 건과 그 앞 48건)을 고정해 놓고 같은 계산을 200회 반복했습니다.
- 그 1건이 시험 데이터(22,740건)에 속하는지는 확인하지 않았습니다. 시험 항목 1·2와 같은 데이터라고 할 수 없습니다.

## 4. 재측정 요청

위 세 가지를 모두 충족하도록 측정 프로그램을 새로 만들었습니다. 재측정을 허용해 주시면 일정에 맞춰 진행하고 화면을 녹화해 제출하겠습니다.

| 항목 | 내용 |
|---|---|
| 측정 대상 | 시험 항목 1·2와 **같은 시험 데이터 22,740건 전체**. 한 건(한 지점의 한 시각)이 판단 1회 |
| 데이터 파일 | `01_시험데이터/시험셋.csv` — 이미 제출한 `01_시험데이터.zip`(SHA-256 `4639543410f55317851a5d7fbf6f69a435f608b7b61e8558d66ca92dc890de0d`)과 같은 파일. 측정 전에 건수와 순서를 대조하고 파일 해시를 결과에 적음 |
| 입력 | 각 건마다 그 지점의 직전 48시간과 그 시각의 관측 |
| 측정 구간 | ① 입력 변수 계산 → ② 위험 판단(1시간·3시간 모델 38개 추론, 복합위험, 판단근거 추출) → ③ 조치 결정 → ④ 이력 기록. 이어서 실행하며 구간 사이에 빈틈이 없음 |
| 기록 | 건마다 한 줄: 번호, 시각, 관측지점, **시작시각, 종료시각**(마이크로초), 구간별 소요시간, 전체(ms) |
| 정합성 | 모든 줄에서 종료시각 − 시작시각 = 구간 4개의 합 = 전체(ms) |
| 최종값 | 전체(ms) 22,740개 값의 합 ÷ 22,740 (중앙값·95번째 백분위·최대도 함께) |
| 판단 프로그램 | 현장 제어기가 쓰는 판단 함수를 그대로 호출. 판단 코드와 모델은 시험 당일과 같고, 실행 전에 해시로 대조 |
| 예상 소요 | 약 20~30분 |

참고 사항

- ②의 모델 추론과 판단근거 추출은 판단 함수 안에서 함께 이뤄져 한 구간으로 잽니다.
- 재는 구간에 넣지 않는 것: 프로그램 시작, 모델 파일 읽기, 데이터 파일 읽기, 결과 파일 쓰기.
- 재측정 값은 시험 당일 값(29.99 ms)과 다르게 나옵니다. 1시간 모델과 이력 기록이 포함되고 입력이 건마다 달라지기 때문이며, 수십 ms 수준으로 예상합니다.
