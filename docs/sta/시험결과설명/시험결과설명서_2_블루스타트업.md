## 4. 시험 항목 1 — 객체탐지 성능 (mAP@0.5)

**시험 목적** — 모델이 새우를 얼마나 정확하게, 빠짐없이 찾는지 측정한다.

**결과 도출 과정**

1. 예측 상자와 정답 상자의 겹침 정도를 구한다.

```
IoU = 예측 상자와 정답 상자가 겹친 넓이 ÷ 두 상자를 합친 넓이
```

2. IoU 가 0.5 이상이고 그 정답이 아직 다른 예측과 짝지어지지 않았으면 맞음(TP), 아니면 틀림(FP)으로 한다. 한 정답에는 예측 하나만 짝지어지고, 신뢰도가 높은 예측이 먼저 가져간다.
3. 445장의 예측 상자 13,211개를 신뢰도가 높은 순서로 한 줄로 세운다(「전체순위」).
4. 위에서부터 누적하며 순위마다 다음을 구한다.

```
정밀도(n) = n번째까지의 누적 TP ÷ (누적 TP + 누적 FP)
재현율(n) = n번째까지의 누적 TP ÷ 전체 정답 수(3,699)
```

5. 정밀도·재현율 곡선을 재현율 0.00, 0.01, … , 1.00 의 101개 지점에서 읽어 평균한다(COCO 방식 101점 보간). 각 지점에서는 재현율이 그 값 이상인 구간의 정밀도 최댓값을 읽는다.

```
AP = (101개 지점에서 읽은 정밀도의 합) ÷ 101
```

6. 클래스가 `shrimp` 하나이므로 mAP@0.5 = AP 이다.

mAP 는 이미지별 값의 평균이 아니라 전체 예측을 한 줄로 세워 계산한 값이며, 신뢰도 임계값과 무관하게 곡선 전체로 계산합니다.

**결과** — mAP@0.5 = **0.9307** (기준 0.75 이상 충족)

**참고값** — 운영 신뢰도 임계값 0.25 에서의 Precision = TP ÷ (TP + FP), Recall = TP ÷ (TP + FN), F1 = 2PR ÷ (P + R), 그리고 mAP@0.5:0.95(IoU 기준을 0.50~0.95 로 0.05 씩 바꿔 10번 잰 AP 의 평균). 값은 `03_최종결과.json` 에 있습니다.

## 5. 시험 항목 2 — 개체수 계수 오차율

**시험 목적** — 모델이 센 마릿수가 실제 마릿수와 얼마나 가까운지 측정한다. 현장에서 쓰는 값은 상자의 위치가 아니라 마릿수이므로 따로 측정한다.

**결과 도출 과정**

1. 이미지마다 신뢰도가 운영 임계값 0.25 이상인 예측 상자 수를 검출 수로 한다.
2. 이미지마다 오차율을 구한다.

```
이미지 한 장의 오차율 = |검출 수 − 정답 수| ÷ 정답 수
```

3. 이미지별 오차율을 평균한다.

```
계수 오차율 = (이미지별 오차율의 합) ÷ (정답이 1마리 이상인 이미지 수)
```

4. 정답이 0마리인 이미지는 나눌 수 없어 평균에서 제외하고, 그 이미지들의 헛검출 수를 따로 적는다.

**계산 예** — 정답 10마리인 이미지에서 9마리를 검출하면 |9 − 10| ÷ 10 = 10%

**결과** — 계수 오차율 평균 = **2.79%** (기준 20% 이하 충족)

**참고값** — 오차율의 중앙값·최대, 오차 20% 안에 든 이미지의 비율, 탐지율의 95% 하한. 값은 `03_최종결과.json` 에 있습니다.
