## 4. 시험 항목 1 — 위험 놓침 방지율 (사례 단위)

**시험 목적** — 실제 위험사례(위험 상태가 이어진 구간) 가운데 AI 가 한 번이라도 위험으로 판단한 사례의 비율을 판정 항목별로 측정한다.

**결과 도출 과정**

1. `02_시점별_결과.csv` 에서 `위험사례ID` 가 같은 줄을 한 사례로 묶는다.
2. 그 사례의 줄 가운데 `예측등급` 이 1 이상인 줄이 한 번이라도 있으면 탐지(1), 없으면 미탐지(0)로 한다. 이 결과가 `02_사례별_결과.csv` 의 「탐지(0/1)」 열이다(전체 1,942줄).
3. 판정 항목마다 다음을 계산한다.

```
놓침 방지율 = 탐지한 사례 수 ÷ 사례 수
```

**계산 예** — 복합위험 3시간(최저값): 위험사례 18건 가운데 16건 탐지 → 16 ÷ 18 = **0.889**
고온·건조 1시간: 위험사례 316건 가운데 305건 탐지 → 305 ÷ 316 = **0.965**

**결과**

|---|---|---|---|---|
| 고온·건조 1시간 | 316 | 305 | 0.965 | 충족 |
| 고온·건조 3시간 | 316 | 310 | 0.981 | 충족 |

10개 항목 모두 0.85 이상이며 최저값은 0.889 입니다. (참고) 10개 항목의 평균은 0.942 입니다.

시간 단위 재현율 = (정답등급 1 이상이고 예측등급 1 이상인 줄 수) ÷ (정답등급 1 이상인 줄 수)

위험 시각 하나하나를 맞혔는지 보는 값으로, 0.85 이상은 7개 항목입니다. 강우·과습과 복합위험은 관측값만으로 강우의 시작을 미리 알기 어려워 낮게 나옵니다.

## 5. 시험 항목 2 — 종합점수 (판정 조치단위 Macro F1)

**시험 목적** — 위험 등급 판정의 종합 성능을 판정 항목별로 측정한다. 위험 시각이 전체의 일부뿐이라 정확도 대신 드문 등급도 같은 비중으로 보는 Macro F1 을 쓴다.

**평가단위** — 주의와 경계에서 농가가 하는 조치가 다른 유형(고온·건조, 병해 유리환경)은 3등급으로, 조치가 같은 유형(강우·과습, 저온·서리, 복합위험)은 주의·경계를 합쳐 정상·위험 2등급으로 평가한다.

**결과 도출 과정**

1. 판정 항목마다 `정답_평가단위` × `예측_평가단위` 의 줄 수를 세어 혼동행렬을 만든다.
2. 등급 k 마다 TP(정답도 예측도 k), FP(정답은 k 가 아닌데 예측이 k), FN(정답은 k 인데 예측이 k 가 아님)을 센다.
3. 다음을 계산한다.

```
F1_k     = 2 × TP_k ÷ (2 × TP_k + FP_k + FN_k)
Macro F1 = (등급별 F1 의 합) ÷ 등급 수
```

**계산 예 1** — 고온·건조 3시간(3등급, 최저값)

| 정답 \ 예측 | 정상 | 주의 | 경계 |
|---|---|---|---|
| 정상 | 18,201 | 279 | 179 |
| 주의 | 108 | 313 | 65 |
| 경계 | 47 | 85 | 3,463 |

| 등급 | TP | FP | FN | F1 |
|---|---|---|---|---|
| 정상 | 18,201 | 155 | 458 | 0.9834 |
| 주의 | 313 | 364 | 173 | 0.5383 |
| 경계 | 3,463 | 244 | 132 | 0.9485 |

Macro F1 = (0.9834 + 0.5383 + 0.9485) ÷ 3 = **0.823**

**계산 예 2** — 복합위험 3시간(2등급)

| 정답 \ 예측 | 정상 | 위험 |
|---|---|---|
| 정상 | 22,624 | 13 |
| 위험 | 41 | 62 |

정상 F1 = 2×22,624 ÷ (2×22,624 + 41 + 13) = 0.9988, 위험 F1 = 2×62 ÷ (2×62 + 13 + 41) = 0.6966
Macro F1 = (0.9988 + 0.6966) ÷ 2 = **0.848**

**결과**

|---|---|---|---|
| 고온·건조 1시간 | 3등급 | 0.911 | 충족 |
| 고온·건조 3시간 | 3등급 | 0.823 | 충족 |
| 강우·과습 1시간 | 2등급 | 0.911 | 충족 |
| 강우·과습 3시간 | 2등급 | 0.861 | 충족 |
| 병해 유리환경 1시간 | 3등급 | 0.937 | 충족 |
| 병해 유리환경 3시간 | 3등급 | 0.911 | 충족 |
| 저온·서리 1시간 | 2등급 | 0.957 | 충족 |
| 저온·서리 3시간 | 2등급 | 0.940 | 충족 |
| 복합위험 1시간 | 2등급 | 0.890 | 충족 |

10개 항목 모두 0.80 이상이며 최저값은 0.823 입니다. (참고) 10개 항목의 평균은 0.899 입니다. 항목 간 평균으로 판정하지 않고 항목 각각으로 판정합니다.

## 6. 시험 항목 3 — AI 판단 시간

**시험 목적** — 입력 자료를 받아 위험을 판단하고 조치를 결정·기록하기까지 걸리는 시간을 측정한다.

**측정 대상** — 시험 항목 1·2와 같은 시험 데이터 22,740건 전체. 한 건(한 지점의 한 시각)이 판단 1회이며, 각 건마다 그 지점의 직전 48시간과 그 시각의 관측을 입력으로 준다. 2026-11-22 14:41:21 ~ 15:04:03 에 시험 PC 에서 측정했다(입회 없이 진행한 재측정).

**측정 구간** — ① 입력 변수 계산 → ② 위험 판단(1시간·3시간 모델 38개 추론, 복합위험, 판단근거 추출) → ③ 조치 결정 → ④ 이력 기록. 이어서 실행하며 구간 사이에 빈틈이 없다. 프로그램 시작, 모델·데이터 파일 읽기, 결과 파일 쓰기는 재지 않는다.

**결과 도출 과정**

1. `sta_time_testset.py` 가 시험 데이터를 한 건씩 판단하며 `07_판단시간_데이터별.csv` 에 한 줄씩 적는다(22,740줄). 열은 번호, 시각, 관측지점, 시작시각, 종료시각, 구간별 소요시간(ms), 전체(ms)이다.
2. 모든 줄에서 종료시각 − 시작시각 = 구간 4개의 합 = 전체(ms) 이다.
3. 다음을 계산한다.

```
평균 = 전체(ms) 22,740개 값의 합 ÷ 22,740
```

**결과**

| 구간 | 평균 | 중앙값 | 95번째 백분위 | 최대 |
|---|---|---|---|---|
| ① 입력 변수 계산 | 12.863 ms | 12.513 ms | 13.737 ms | 54.020 ms |
| ② 위험 판단 | 46.218 ms | 41.166 ms | 60.016 ms | 73.308 ms |
| ③ 조치 결정 | 0.092 ms | 0.090 ms | 0.108 ms | 0.387 ms |
| ④ 이력 기록 | 0.516 ms | 0.494 ms | 0.610 ms | 10.211 ms |
| **전체** | **59.690 ms (0.060초)** | 55.290 ms | 73.659 ms | 120.067 ms |

기준(평균 30초 = 30,000 ms 이내)을 충족한다.

**시험 당일(2026-11-19) 측정 — 참고** — 당일에는 입력 1건(전체 데이터셋의 가운데 위치 한 건과 그 앞 48건)을 고정해 200회 반복했고, 시작·종료 시각은 기록하지 않았다. 「끝에서 끝까지」 평균 29.99 ms 는 입력 변수 계산 + 3시간 모델 19개 추론 + 판단근거 추출 + 조치 결정을 잰 값으로, 1시간 모델 19개 추론과 이력 기록은 들어 있지 않다. `06_판단시간_회차별.csv` 의 여섯 열은 각각 따로 200회 잰 값이라 같은 줄을 더해도 「끝에서 끝까지」와 같지 않다(다섯 단계 평균의 합 45.529 ms).

## 7. 재계산 검증

`sta_recompute.py` 는 결과 CSV 만 읽어(모델·원천자료를 읽지 않음) 위 산식으로 혼동행렬, 등급별 F1, Macro F1, 사례 단위 놓침 방지율, 시간 단위 재현율, 판단시간 통계를 다시 계산하고 `03_최종결과.json` 과 한 값씩 비교합니다. 시험 시 모든 값이 일치했고 종료 코드는 0 이었습니다. 계산식은 프로그램 첫머리 주석에 적혀 있습니다.
