## 3. 워드마크 (임시)

`<symbol id="amp-mark">` 하나로 되어 있고, 모든 자리가 `<use href="#amp-mark">`로 이것을 참조한다.

- **심볼**: 둥근 정사각 타일 안에 다음 셋을 넣었다.
  - 두 획으로 그린 **A**
  - A의 가로획 자리에 **물결선** — 수조의 수면
  - 꼭짓점의 **점** — 측정점
- **글자**: `AMP`(굵게, 자간 +0.06em) + 제품명(보통 굵기, `--brand-text` 색)
- 색은 토큰 세 개로 정한다: `--logo-tile` · `--logo-line` · `--logo-dot`
- 크기: 상단 바 17px, 기기 정보 24px, 부팅 40px. 모두 `font-size` 하나로 비례한다
- **에이엠피의 실제 로고를 흉내 내거나 추측한 것이 아니다.** 일부러 단순한 기하 도형으로 만들었다. 바깥 패널 구석의 "임시 브랜드 시안" 표식은 기기 화면 안에는 넣지 않았다.

## 4. 색 — 3안

### 4-1. 원칙

1. **상태색은 브랜드와 분리한다.** 정상·주의·위험 색은 세 안이 같고, 다크와 라이트 두 벌만 있다. 브랜드가 바뀌어도 "빨강 = 위험"은 그대로다.
2. **정상은 조용하게 표시한다** — ISA-101 고성능 HMI 관행을 따랐다. 정상 칸은 테두리가 중립색이고 작은 ✓ 표지만 붙는다. 색 면적은 주의·위험에만 쓴다. 그래서 브랜드 강조색이 정상 초록과 조금 닮아도 혼동이 적다.
3. **색만으로 말하지 않는다**(색맹 대응). 상태마다 아래 셋이 함께 바뀐다.

   | 상태 | 아이콘 모양 | 글자 | 칸 처리 |
   |---|---|---|---|
   | 정상 | 원 안 ✓ | 정상 | 중립 테두리 |
   | 주의 | 삼각 ! | 주의 | 주황 테두리 + 옅은 면 |
   | 위험 | 팔각 ! | 위험 | 굵은 빨강 테두리 + 채운 표지 |
   | 센서 오류 | 플러그 빗금 | 센서 오류 | **점선** 테두리 + 중립색 |

   적록색맹에게 주의와 위험(주황·빨강)이 비슷하게 보여도 모양·글자·테두리 굵기로 구별된다.
4. 화면 CSS에는 hex를 직접 쓰지 않는다. 모든 색은 `:root` 토큰을 거친다. 예외는 베젤(하드웨어)과 바깥 패널의 색 견본뿐이다.

### 4-2. 3안 요약

| 안 | 이름 | 근거 | 장점 | 주의할 점 |
|---|---|---|---|---|
| **①** (추천) | 딥네이비 + 시안 | 산업용 계측기·SCADA의 관례, 물을 떠올리게 함 | 상태색 셋과 겹치는 색이 하나도 없다. 신뢰감 | 흔하다. 차별성은 워드마크가 맡아야 한다 |
| ② | 딥 틸 + 샌드 | 바다·연안 양식장, 다른 계측기와 다른 인상 | 라이트 모드의 모래색 바탕이 햇빛 아래에서 눈부심이 덜하다 | 예시의 "틸 + 앰버"에서 **앰버를 샌드(채도 낮은 뉴트럴)로 바꿨다.** 앰버는 '주의' 색과 겹치기 때문이다. 틸 강조색은 정상 초록과 색상 차이가 약 25°로 가깝다 → 원칙 2로 완화 |
| ③ | 그래파이트 + 라임 | 공구·현장 장비 느낌, 튼튼함 | 다크 대비가 가장 높다(라임 12.9:1) | 적록색맹에게 라임이 '주의' 주황과 비슷한 노란 계열로 보일 수 있다. 상태 표지는 아이콘·글자를 함께 쓰므로 판정은 틀리지 않지만 **세 안 중 이 위험이 가장 크다.** 라이트 모드에서는 라임을 글자색으로 쓸 수 없어 올리브(`#3D5A0A`)로 바꾼다 |

## 5. 타이포 · 간격 · 아이콘 · 모션

**타이포** (800×480 기준 px)

| 쓰임 | 크기 / 굵기 |
|---|---|
| 대시보드 측정값 | 72 / 700, `tabular-nums`, 자간 −0.02em |
| 단위 | 22 / 600, `--text-2` |
| 그래프 현재값 | 28 / 700 |
| 화면 제목 | 20 / 700 |
| 값 칸 이름 | 18 / 600 |
| 권고 띠 문장 | 18 / 700 |
| 본문·버튼 | 16 / 600 |
| 보조 | 13–15 |
| 최소 | 12 (그래프 축 13, Powered by 12) |

- 숫자는 `Intl.NumberFormat(ko-KR|en-US|vi-VN|id-ID)`로 포맷한다. **vi·id는 소수점이 쉼표**(28,4)라서 언어를 바꾸면 숫자 표기도 따라 바뀐다.

**간격**

- 4/8 리듬을 쓴다. 화면 가장자리 12, 칸 사이 10, 카드 안쪽 12–18, 상단 바 높이 56
- 스크롤은 없다. 모든 화면이 800×480 안에 들어간다

**터치**

| 요소 | 크기 |
|---|---|
| 모든 버튼·칩·탭·토글 | 최소 48×48 |
| 키패드 | 52 |
| 값 칸 | 약 383×159 |
| 설정 타일 | 약 383×92 |
| 권고 띠 | 64 |
| 인접 목표 사이 간격 | 6–10 |

**눌림·포커스**

- 누르면 `filter: var(--press)`로 밝기만 바뀐다(다크 1.15 / 라이트 0.93). 레이아웃은 움직이지 않는다.
- 포커스 링은 3px `--focus`에 오프셋 2px이다.

**아이콘**

- 인라인 SVG 스프라이트 한 벌. 24 격자, 선 2px, 끝 둥글게, 외곽선 하나로 통일했다. 이모지는 쓰지 않는다.
- 크기 토큰은 `.ic.s` 20 / `.ic` 24 / `.ic.l` 28 셋뿐이다.

**모션**

| 동작 | 처리 |
|---|---|
| 화면 전환 | 0.18초 페이드 |
| 경보 띠 | 처음 약 6초만 맥동, 그다음 고정된 빨강 |
| 부팅 진행 막대 | 1.5초 |
| 연결 대기 점 | 깜빡임 |

- `prefers-reduced-motion`이면 모두 즉시 끝난다.
- 값이 갱신될 때(3초마다)는 애니메이션이 없다. 화면이 계속 움직이면 경보가 눈에 띄지 않는다.

### 시안에서 일부러 지금 장비와 다르게 한 것

- **하단 상태줄을 없앴다.** 서버 상태를 상단 칩으로 올려 값 칸을 키웠다(값 56px → 72px).

- 연결 안내에서 **URL을 빼고** "AMP 앱"을 기준으로 단계를 적었다. 포털 주소가 아직 없다.

### 7-3. 브랜드 문자열

`Shrimp365`·`Farm365`가 11곳에 있다:

- `<title>`, `#brand`
- `BRANDS` 표 (679행 부근)
- `pair_desc`
- `pair_url` 기본값 `www.shrimp365.kr`
- 로거 이름, 설치 스크립트 경로

이 가운데 **화면에 보이는 것**만 설정값으로 빼고, 기기 정보 하단에 `Powered by Shrimp365` 한 줄을 넣는다. 로거 이름과 경로는 화면에 나오지 않으므로 그대로 둬도 된다.

### 7-4. 권장 방식

장비 코드를 복제(fork)하지 말고 **에디션 설정 하나**로 나눌 것을 제안한다. 예: `edition = "amp"`.

- `BRANDS`에 `amp` 항목을 추가한다: 이름 · 모델 · 로고 SVG · 포털 문구
- AMP판에서는 모드 전환, 양액, 스마트팜 환경 화면, 지그비 농업 센서 화면을 숨긴다
- 토큰 블록은 `:root[data-edition="amp"]`로 덮어쓴다

이 결정은 민준·서연 몫이다.

### 7-5. 작업량 추정: **중간** (서연 기준 3~5일 + 태양 캡처 회귀 1일)

**작게 끝나는 부분**

- `--brand` 변수 구조와 `I18N` 모양이 이미 시안과 같다. 토큰을 늘리고 키를 추가하면 된다.
- 판정(`limits.py` → JS `level()`)과 그래프 적정 띠는 이미 있다.

**시간이 드는 부분**

1. 하드코딩 hex 162곳을 토큰으로 치환
2. 대시보드 재배치 — 하단 줄 삭제, 칩 이동, 값 칸 안의 표지·범위·추세 추가
3. AI 화면·기기 정보·설정 타일 다시 쓰기
4. `fault` 상태 표현
5. `Intl` 숫자 포맷
6. 에디션 분기와 농업 기능 숨김

**확인이 필요한 부분**

- **1시간 변화량**과 **AI 근거 한 줄**이 지금 수집기 스냅샷에 있는지 확인해야 한다. 없으면 수집기(`anomaly.py`·`advice.py`) 쪽 작업이 더해져 **큼**으로 올라간다.
- 4,100줄 단일 파일이라 회귀 위험이 있다. 화면 캡처 42장 기준으로 전후 비교해야 한다.

## 8. 열린 질문 · 위험

1. **전도도 환산**: 시안은 염도 × 1.6으로 근사했고(18.2 ‰ → 29.1 mS/cm), 전도도 판정 밴드도 염도 밴드에 같은 배수를 곱했다. 실제로는 온도 보상(PSS-78 등) 환산이 필요하다. 지훈 확인 → 서연 구현.
2. **상표**: 제품명 3안 모두 검색 전이다. AquaGuard는 충돌 가능성이 높다(§2).
3. **포털·앱 이름**: 연결 단계가 "AMP 앱"을 전제로 한다. 앱이 없고 웹만 있다면 4단계 문구와 주소 표시를 다시 넣어야 한다.
4. **AI 권고의 범위**: 화면은 "권고만 — 설비를 직접 켜고 끄지 않음"이라고 약속한다. 에이엠피가 자동 제어를 원하면 화면·안전 설계를 따로 해야 한다.
5. **경보 소리**: 시안은 시각 경보만 다룬다. 부저·외부 경광등을 연동한다면 [확인] 버튼이 소리를 끄는 동작이 되어야 한다.
6. ③안(라임)은 적록색맹 위험이 가장 크다(§4-2). 고객이 ③을 고르면 '주의' 색을 더 붉은 주황으로 옮길지 검토해야 한다.
