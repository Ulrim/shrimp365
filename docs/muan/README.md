# 무안 양식장 3D — 도면 판독 기록

`/farms/3d` 화면이 세우는 모형의 근거를 남긴다. 수치를 고칠 일이 생기면
`lib/farm3d/layout.ts` 하나만 손보면 되고, 이 문서는 그 숫자가 어디서 왔는지
설명한다.

## 출처

「지상 1층 평면도 · 가설건축물(새우양식장)」 건축허가 도면 1장.

## 도면에서 직접 읽은 값

| 항목 | 값 | 도면 근거 |
|---|---|---|
| 대지 가로 | 63,000 mm | 상·하단 전체 치수 |
| 대지 세로 | 27,000 mm | 우측 전체 치수 (13,500 + 13,500) |
| 대지 모접기 | 2,000 + 2,000 | 네 귀퉁이 (평면이 팔각형) |
| X방향 기둥 간격 | 4,000 + 3,000×18 + 1,000 + 4,000 | 하단 치수선 |
| Z방향 기둥 간격 | 4,000 + 4,750×4 + 4,000 | 우측 치수선 |
| 건물 상단 변 | 57 m | 상단 라벨 |
| 건물 하단 변 | 55 m | 하단 라벨 |
| 1번 수조 | 12×55 + 10×2 + (2×2.5)/2 = 682.5 m² | 도면 기재 산식 |
| 2번 수조 | 12×55 = 660 m² | 도면 기재 산식 |
| 합산 | 1,342.5 m² | 도면 기재 「합산」 |
| 외피 | 차광막 겹마감 + 아웃도어비닐 1겹 | 상·하단 지시선 |

**도면의 두 면적 산식은 사각 수조 2기에 대응한다.** 건물 안이 통째로 수조
두 기이고, 둘을 가르는 벽이 가운데 기둥 열 위에 선다.

## 건물 외곽선을 어떻게 정했나

도면의 굵은 실선은 단순한 사각형이 아니다. 우측 상단이 튀어나와 있고 모가
접혀 있다. 도면에 적힌 산식이 그 모양을 그대로 설명하므로, 산식을 폴리곤으로
되돌렸다.

건물 중심을 원점으로, +X는 도면 오른쪽, +Z는 도면 아래쪽:

```
(-27.5, -12) → (29.5, -12) → (29.5, -2) → (27.5, 0.5) → (27.5, 12) → (-27.5, 12)
```

이 폴리곤은 세 값을 동시에 만족한다 — 셋 다 맞아떨어져야 도면을 옳게 읽은
것이다:

- 상단 변 `29.5 − (−27.5) = 57.0 m` → 도면 「57m」
- 하단 변 `27.5 − (−27.5) = 55.0 m` → 도면 「55m」
- 신발끈 공식 넓이 `1,342.5 m²` → 도면 「합산 1342.5」

화면 상단 「연면적」 카드가 이 검산을 매번 다시 돌린다. 폴리곤을 잘못 고치면
카드에 `⚠ 도면 산식과 불일치`가 뜬다.

## 수조 두 기

| 자리 | 이름 | 윤곽 넓이 | 도면 | 벽 안쪽 | 담수(수심 1.2 m) |
|---|---|---|---|---|---|
| `T1` | 1번 수조 | 682.4 m² | 682.5 | 648.4 m² | 약 778 m³ |
| `T2` | 2번 수조 | 660.0 m² | 660 | 626.75 m² | 약 752 m³ |

1번 수조의 0.1 m² 차이는 격벽 위치 때문이다. 도면의 모접기 선은 `z = 0.5`
까지 내려오는데, 두 수조를 가르는 벽은 가운데 기둥 열(`z = 0`)에 선다. 모접기를
`z = 0` 에서 끊었고, 그 결과가 682.4 m² 다. 전체의 0.015 % 라 그대로 뒀다.

벽 안쪽 윤곽은 `insetPolygon()` 이 만든다. 꼭짓점을 도형 중심 쪽으로 당기는
방식은 55 × 12 처럼 길쭉한 도형에서 짧은 변과 긴 변의 두께가 완전히 달라지므로
쓰지 않는다. 각 변을 평행하게 민 직선의 교점을 새 꼭짓점으로 잡아야 사방
두께가 고르게 나온다 — 2번 수조 안쪽이 정확히 `54.5 × 11.5 = 626.75 m²` 로
떨어지는 것이 그 확인이다.

## 도면에 없어서 추정한 값

받은 도면은 건축허가용이라 평면 윤곽과 기둥 그리드만 있다. 아래는 실측이
오면 바꿔야 하는 값이고, 화면에서도 「확인이 필요한 값」으로 그대로 고지한다.

| 항목 | 임시값 | 필요한 자료 |
|---|---|---|
| 수조 수심 | 1.2 m | 단면도 |
| 수조 벽 높이 | 1.4 m | 단면도 |
| 수조 벽 두께 | 0.25 m | 구조 상세 |
| 격벽 위치 | z = 0 (가운데 기둥 열) | 평면 상세 |
| 처마 높이 | 3.0 m | 단면도 또는 입면도 |
| 용마루 높이 | 5.5 m | 단면도 또는 입면도 |
| 기둥 관경 | Ø150 mm | 구조 상세 |
| 건물의 대지 내 위치 | 가운데 정렬 | 이격거리 표기 |
| 기계실·여과조·급배수로 | 없음 | 설비 도면 |
| 방위(북쪽) | 없음 | 배치도 방위 표시 |

## DB 수조와의 연결

3D의 수조 자리(`T1`·`T2`)와 DB의 `tanks` 레코드는 지금 **이름순 순서 매핑**으로
붙인다. 수조마다 자리를 지정하는 열을 `tanks` 테이블에 두는 쪽이 맞지만, 그
전까지는 순서 매핑이 가장 덜 틀린다. 자리보다 등록된 수조가 많으면 남는 수조는
3D에 나오지 않고, 그 수를 화면에서 알려 준다.
