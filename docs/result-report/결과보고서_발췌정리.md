## 1. 과제 개요

### 1-1. 추진배경 (요약문·9쪽에서 발췌)
- 흰다리새우 양식은 수질 변화, 급이 조절, 질병, 폐사 위험에 민감해 **생산성 편차가 크고 운영 난도가 높음**
- 현장은 **수기 기록·엑셀·운영자 경험**에 의존 → 폐사·성장 부진·수질 악화 원인을 **사후에 추정**하는 수준
- 해양수산부 「양식산업발전 기본계획(2024~2028)」, 스마트양식 빅데이터센터 등 정책 방향과 부합하나, 데이터가 일부 어종에 편중되고 표준 규격이 부족함
- 본 과제는 양식 데이터를 표준화하고 AI 분석을 적용해 **경험 중심 운영 → 데이터 기반 운영**으로 전환하는 것

**현장 문제 정리표 (9쪽)** — 결과보고서 '해결한 문제' 대비표로 재활용 가능

| 구분 | 현장 문제 | 사업화 관점의 영향 |
|---|---|---|
| 데이터 단절 | 수질·사료·성장·폐사·진단 데이터가 개별 기록으로 분산 | 원인 추적·예측 분석 곤란 |
| 경험 의존 | 숙련자 감각으로 급이·환수·미생물 투입 결정 | 신규·청년·귀어인 진입장벽 |
| 수기 기록 | 엑셀·종이일지·메신저 사진 | 누락·오입력·분석 불가 |
| 사후 대응 | 폐사·질병·수질 악화 이후 대응 | 손실 후 복구비용 증가 |
| 표준 운영 부재 | 양식장별 관리 기준 상이 | 재현 가능한 생산성 확보 곤란 |
| 실증 데이터 부족 | 회차별 성과 비교 데이터 부족 | 도입 효과 입증 어려움 |

## 6. 작성 시 주의 — 계획서 내부 불일치

결과보고서에서 목표치를 인용할 때 다음을 통일해야 합니다.

1. **AI 분석 목표 개수**: 요약문 "AI 분석 기능 **3종** 이상" vs 1-1쪽·17쪽 "AI 분석모델 **1종** 이상". 실적은 두 기준 모두 충족하는지 명시하는 편이 안전함
2. **지재권 수치**: 특허 **출원 1건**이 목표인데 17쪽 기술사업화 표의 '지재권창출(건)'은 사업기간 내 **0**. 표의 '창출'이 등록 기준이라고 보면 맞지만, 결과보고서에서는 "출원 1건(등록 0건)"으로 구분해 적을 것
3. **마케팅 결과물**: 17쪽 성과지표는 결과물 "결과보고서", 24쪽은 "서비스 브로슈어 1식 + 영업제안서 1식". 결과보고서에는 브로슈어·제안서를 실물 결과물로 제출
4. **성과 집계 기간**: 수행기간은 **11.30** 종료인데 17쪽 성과표는 "협약일~'26.12". 매출·계약 실적의 집계 기준일을 확인할 것
5. **신규계약 표현**: 요약문 "신규계약 2건" vs 1-1쪽 "신규계약 **또는 유료전환 후보** 2건". 실적이 '후보' 수준이면 1-1쪽 표현을 인용
