# 제작도면 — 수질 모니터링 장비 함체

가공을 맡기기 위한 도면입니다. 설계 근거와 배경은 [../PACKAGING.md](../PACKAGING.md) 에 있습니다.

```
enclosure/
├── xlsx/hardware.xlsx      ★ 하드웨어 사양 통합 엑셀 (부품·결선·좌표·검사)
├── make-xlsx.py            위 엑셀 생성기
├── ENCLOSURE.md            외함 설계서 (요구 형상·성능·검증 기준)
├── WIRING.md               내부 배선 설계서 (결선표·핀맵·검사)
├── PARTS.md                기성품 구매 목록 (모델·수량·확인 상태)
├── make-drawings.py        제작도면 생성기 (SH-01…07)
├── make-wiring.py          배선 계통도 생성기 (W-01…04)
├── make-3d.py              3D 조립 모델 생성기
├── dxf/                    가공용 — 업체에 보내는 파일
├── svg/                    검도용 도면 + 배선 계통도
├── model/                  3D 모델 (OBJ + MTL + STL)
└── png/                    3D 렌더 미리보기
```

부품 발주는 **[PARTS.md](PARTS.md)** 를 보십시오. 함체를 먼저 사서 실측한 뒤 도면을
다시 생성하는 것이 정해진 순서입니다.

## 발주 방법

1. **함체를 먼저 구매**합니다. 요구 사양은 [PACKAGING.md 4.3](../PACKAGING.md#43-선정-조건) 입니다.
2. 함체 실물의 **도어 평탄부 / 백플레이트 / 하부면 유효 치수를 실측**합니다.
3. `make-drawings.py` 의 `PARAMS` 를 실측값으로 고치고 다시 돌립니다.
4. `dxf/` 의 파일을 가공 업체에 보냅니다. `svg/` 는 함께 보내 치수·주기를 읽게 합니다.

3번을 건너뛰지 마십시오. 카탈로그의 외형치수와 내부 유효치수는 벽 두께와 실링 립 때문에
20 mm 이상 차이 납니다. 지금 값은 **가정치**입니다.

```bash
python3 make-drawings.py
```

의존성이 없습니다. 파이썬 3 만 있으면 됩니다.

## DXF 읽는 법

DXF R12 형식입니다. AutoCAD, LibreCAD, QCAD, Fusion 360, 대부분의 CAM 이 그대로 엽니다.

| 레이어 | 색 | 뜻 |
|---|---|---|
| `CUT` | 빨강 | **가공선.** 이 선만 자르고 뚫습니다 |
| `MARK` | 초록 | 위치 마킹·중심선. 가공하지 않습니다 |
| `REF` | 회색 | 참고 형상(부품 외형, 함체 외곽). 가공하지 않습니다 |
| `DIM` / `NOTE` | — | SVG 에만 있습니다 |

**업체에 보낼 때 `CUT` 외의 레이어는 끄거나 지워 주십시오.** 참고선을 가공선으로 오해해
함체에 없는 구멍이 뚫리는 사고가 이 방식에서 가장 흔한 실수입니다.

원점은 도면마다 다릅니다.

| 도번 | 원점 |
|---|---|
| SH-01 | 도어 평탄부 중심 |
| SH-02 | X = 하부면 좌우 중심, Y = **후면 외벽** |
| SH-03 | 백플레이트 중심 |
| SH-04, SH-05 | 부품 중심 |

## 공차

도면에 따로 적지 않은 치수는 아래를 따릅니다.

| 항목 | 공차 |
|---|---|
| 구멍 중심 위치 | ± 0.5 mm |
| 구멍 지름 | +0.2 / −0.0 mm |
| 개구부 176 × 94 | ± 0.5 mm |
| 압착 프레임 외곽 | ± 0.3 mm |
| 절곡 각도 (SH-05) | ± 1° |

개구부는 크게 뚫리면 되돌릴 수 없습니다. **작게 뚫고 맞춰 넓히십시오.**

## 실측 확인이 끝나야 확정되는 치수

지금 도면에 들어 있지만 **실물로 검증되지 않은** 값입니다. 시제품 1대에서 확인하십시오.

| 값 | 현재 | 확인할 것 |
|---|---|---|
| 함체 300 × 300 × 165, 평탄부 265 × 265 | 카탈로그 가정치 | 구매한 함체 실측 |
| 디스플레이 194 × 111 / 활성 155 × 86 | 공식 사양 | 유리 뒷면 가장자리에 개스킷 붙일 평탄면이 편측 8.5 mm 나오는가 |
| M12 패널 구멍 Ø16.5 | M16×1.5 전면체결형 기준 | 구매한 커넥터의 데이터시트. 후면체결형·2점나사형은 치수가 다름 |
| 압착 프레임 창 178 × 95 | 접촉대 8 mm 로 산출 | 디스플레이 뒷면 부품과 간섭이 없는가 |
| 스탠드오프 길이 | SH-06 스택으로 산출 | 개스킷 압축 후 실제 높이 (도어 내면 ~ 프레임 상면) |

마지막 항목이 특히 중요합니다. 스탠드오프 길이가 개스킷 압축률을 결정하는데,
목표는 **2 mm 폼이 1.0~1.4 mm 로 눌리는 것**입니다. 길면 방수가 안 되고 짧으면 유리가 깨집니다.
시제품에서 실측해 확정한 뒤 발주하십시오.

## 3D 조립 모델

기성품을 실제 치수대로 함체에 넣어 본 모델입니다. **치수를 `make-drawings.py` 의 `PARAMS`
에서 그대로 읽어 쓰므로 도면과 어긋나지 않습니다** — 함체를 실측해 `PARAMS` 를 고치면
도면과 3D 가 함께 갱신됩니다.

```bash
python3 make-3d.py
```

| 파일 | 용도 |
|---|---|
| `model/enclosure.obj` + `.mtl` | 부품별로 이름·색이 붙은 조립 모델. Blender · Fusion 360 · FreeCAD · 윈도우 3D 뷰어에서 열립니다 |
| `model/enclosure.stl` | 단색 메시. 빠른 확인·출력용 |
| `png/3d-01-front.png` | 정면 (완성 외관) |
| `png/3d-02-iso.png` | 사시도 |
| `png/3d-03-interior.png` | 도어를 뺀 내부 배치 |
| `png/3d-04-exploded.png` | 분해도 |
| `png/3d-05-connectors.png` | 하부면 커넥터 |

좌표계는 도면과 다릅니다. **X 좌우(−150…+150) / Y 상하(0…300, 바닥이 0) / Z 앞뒤(0=후면,
165=도어)** 이며, 함체 바깥 기준입니다. 도면 SH-03 의 백플레이트 중심은 이 좌표계에서
(0, 150, 17) 입니다.

### 이 모델로 확인한 것

| 확인 | 결과 |
|---|---|
| 백플레이트 부품이 260 × 260 안에 들어가는가 | SMPS 130×98 · 콘센트 Ø86 · 단자대 104×26 → 여유 있음 |
| SMPS 깊이가 함체에 들어가는가 | 후면벽 3 + 이격 12 + 백플레이트 2 + SMPS 40 = **57**, 도어측 디스플레이 스택 28 → 여유 약 80 |
| 하부 커넥터가 내부 부품과 부딪히는가 | 커넥터는 Y 0…25 · Z 100, 백플레이트 부품은 Y 55…160 · Z 17…57 → **간섭 없음** |
| 도어 뒤 파이 + USB-RS485 가 들어가는가 | 파이는 도어 안쪽 디스플레이 뒤(X −20 중심). 변환기 우측 끝 X 97, 도어 평탄부 우단 132.5 → **여유 35** |
| 디스플레이 스택이 도어에 맞는가 | 프레임 137 → 도어 내면 162, 스탠드오프 25 |

### 한계

- **단순화한 형상입니다.** 부품은 실제 외형 치수의 직육면체·원통으로 두었습니다. 방열핀, 단자 돌출, 케이블 반경은 들어 있지 않습니다.
- **간섭 검사를 자동으로 하지 않습니다.** 위 표는 좌표를 손으로 비교한 것입니다. 정밀 간섭 검사가 필요하면 OBJ 를 CAD 로 가져가십시오.
- **하부면·백플레이트의 구멍은 뚫려 있지 않습니다.** 커넥터가 그 자리를 차지하도록 배치만 해 두었습니다. 구멍 치수는 도면(SH-02·SH-03)이 기준입니다.
- 배선은 들어 있지 않습니다.
