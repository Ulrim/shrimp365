결선표**이고, 계통도는 왜 그렇게 되는지 볼 때 씁니다.

## 1. 먼저 읽을 것 — LK1

이 장비에서 **가장 빠뜨리기 쉽고 가장 찾기 어려운 불량**이 여기 있습니다.

선정한 **DDR-30G-5 는 입출력이 4000 VDC 절연**된 DC-DC 입니다. 그래서 벅 입력측 0 V(센서 계,
이 문서에서 **0V-P**)와 출력측 0 V(파이 계, **0V-S**)는 **서로 다른 노드**입니다. 아무것도 하지
않으면 두 계통이 서로 떠 있습니다.

RS485 는 차동 신호지만 **기준이 떠 있으면 공통모드 전압이 트랜시버 허용범위(대개 −7 ~ +12 V)를
벗어나** 통신이 끊깁니다. 증상은 이렇게 나타납니다.

- 배선은 다 맞는데 `CRC 불일치` 가 간헐적으로 뜬다
- 어떤 날은 되고 어떤 날은 안 된다
- 통전 검사·전압 측정으로는 전혀 잡히지 않는다

라즈베리파이 README 가 "**센서 전원의 0 V 와 파이 GND 를 공통으로 묶어 주세요**" 를 반복해서
경고하는 것이 바로 이것입니다.

> **→ `LK1` 은 필수 부품입니다.** 잊을 수 있는 배선 한 가닥이 아니라 도면에 이름이 붙고,
> 결선표에 오르고, 출하 검사에서 도통을 확인하는 항목으로 만들었습니다.

`LK2`(0V-P ↔ PE)는 성격이 다릅니다. SELV 계통에 기준 전위를 주고 서지를 PE 로 빼는 역할이며
**기본 장착**입니다. 다만 접지 루프가 의심되면 떼어 볼 수 있도록 링크로 두었습니다.

| 회로 | 색 | 굵기 | 근거 |

| AC L | 갈색 | 0.75 ㎟ | |
| AC N | 파랑 | 0.75 ㎟ | |
| PE | **녹/황** | 1.5 ㎟ (주간선) / 0.75 (분기) | 다른 색을 쓰지 않습니다 |

| 0V-P | 검정 | 0.75 ㎟ | |

것이라 현장에서 센서 쪽과 함체 쪽 색이 이어집니다.

## 6. 커넥터 핀맵

### 6.1 센서 — M12 A-coded 4핀 (X2 ~ X5)

| 핀 | 신호 | 센서 케이블 색 (Nengshi) | 표준 M12 케이블 색 |
|---|---|---|---|
| 1 | +24 V | 빨강 | 갈색 |
| 2 | RS485 **A** (T/R+) | 초록 | 흰색 |
| 3 | 0 V | 검정 | 파랑 |
| 4 | RS485 **B** (T/R−) | 노랑 | 검정 |

기성 M12 케이블(갈/백/청/흑)을 쓰면 **색이 센서 문서와 달라집니다.** 오른쪽 열을 보고
결선하고, 케이블에 라벨을 붙여 두십시오.

### 6.2 AC — M12 S-coded 4핀 (X1)

| 역할 | 비고 |
|---|---|
| L | 활선 |
| N | 중성 |
| PE | 중앙 접지핀 |

> ⚠ **S-coded 의 핀 번호는 IEC 61076-2-111 로 표준화되어 있습니다.** 임의로 배정하지 말고
> **구매한 커넥터의 데이터시트를 그대로 따르십시오.** 짝이 되는 케이블 플러그도 같은 규격이라
> 번호를 바꾸면 다른 장비와 물렸을 때 사고가 납니다.

**AC 는 S-coded, 센서는 A-coded 로 코딩이 다릅니다.** 둘은 물리적으로 결합되지 않으므로
AC 220 V 를 센서 포트에 꽂는 사고가 기구적으로 막힙니다.

## 7. 배선 규칙

1. **AC 는 오른쪽, 통신은 왼쪽.** DIN 레일의 AC 구역(G1·F·Z1)과 하부면 AC 커넥터가 모두 오른쪽이고, 단자대·센서 커넥터가 왼쪽입니다. 배선이 함체를 가로지르지 않습니다.
2. **RS485 는 AC·SMPS 배선에서 50 mm 이상 띄웁니다.** 불가피하게 교차하면 **직각으로** 지나가게 합니다. 나란히 붙여 가는 것이 가장 나쁩니다.
3. **케이블 덕트를 쓰지 않습니다.** 접착식 타이 앵커로 묶습니다. 백플레이트에 가공이 늘지 않고, 이 크기에서는 덕트가 오히려 공간을 먹습니다.
4. **커넥터 내부 배선은 반드시 한 번 고정합니다.** 커넥터를 조이고 풀 때 도선에 힘이 걸리면 안 됩니다.
5. **USB-C 는 진동으로 빠집니다.** 파이 기판 근처에서 케이블 클램프로 잡습니다.
6. **DSI 리본은 도어 여닫음에 물립니다.** 힌지(좌측) 쪽으로 여유 곡선을 주고 도어 안쪽에 한 번 고정합니다. 꺾이면 화면이 깜빡이다 죽습니다.
7. **실드는 함체측 한쪽만 접지합니다.** 센서측은 띄웁니다. 양쪽 접지는 접지 루프를 만듭니다.
8. **종단저항 120 Ω 은 내부 점퍼로 만들지 않습니다.** 예비 포트(X5)에 꽂는 M12 더미 플러그로 만들어 함체를 열지 않고 넣고 뺄 수 있게 합니다. 케이블이 10 m 를 넘는 현장에서만 씁니다.

## 8. 배선 순서

계통마다 끊어서 하고, 각 단계 끝에서 확인하고 넘어갑니다.

| 단계 | 작업 | 끝내고 확인할 것 |
|---|---|---|
| 1 | 단자대 브리지 삽입 (1–4, 5–8, 9–10 / 각 층) | 브리지 구간이 표와 같은가 |
| 2 | AC 1차 (결선 1–7) → **절연 커버 덮기** | X1 PE ↔ PE1 도통 |
| 3 | 24 V 계통 (8–14) | 극성. Z2 방향 |
| 4 | **G2 출력을 무부하에서 5.15 V 로 조정** | 전압계로 확인. 파이 연결 **전** |
| 5 | 5 V 계통 (15–17, 19–20) | 극성 |
| 6 | RS485 (21–25) | A/B 뒤바뀜 |
| 7 | 센서 커넥터 (26–42) | 4포트 모두 같은 핀에 같은 신호 |
| 8 | **링크 LK1 · LK2 (43–44)** | 도통. **여기서 빠뜨리면 나중에 못 찾습니다** |
| 9 | 신호·데이터 (45–48) | DSI 여유 곡선, USB 클램프 |
| 10 | 전 배선 육안 점검 → 통전 | |

## 9. 배선 검사

출하 검사([PACKAGING.md 14장](../PACKAGING.md#14-출하-검사-eol))에 들어가는 항목 중 배선에
해당하는 것입니다.

| # | 항목 | 판정 |
|---|---|---|
| 1 | X1 : PE ↔ 백플레이트 접지 연속성 | < 0.1 Ω |
| 2 | **XT1-8 (0V-P) ↔ XT2-10 (0V-S) 도통 — LK1** | 도통 |
| 3 | XT1-8 (0V-P) ↔ PE1 도통 — LK2 | 도통 |
| 4 | L+N ↔ PE 절연저항 (500 VDC) | ≥ 10 MΩ |
| 5 | XT1-1 ↔ XT1-5 전압 | 23.5 ~ 24.5 V |
| 6 | XT1-9 ↔ XT2-9 전압 (파이 부하 상태) | 5.05 ~ 5.20 V |
| 7 | X2 ~ X5 각 포트 핀 1–3 전압 | 24 V ± 0.5 |
| 8 | X2 ~ X5 각 포트 핀 2–4 저항 (센서 미연결) | 4포트 동일값 |
| 9 | 센서 통신 — `--scan` | 연결한 ID 가 모두 응답 |
| 10 | 값 읽기 — `--once --dry-run -v` | 4개 값 출력 |

**2번이 이 표의 핵심입니다.** 나머지는 틀리면 바로 드러나지만, LK1 누락은 현장에서 몇 주 뒤에
간헐적 통신 오류로 나타납니다.

8번은 4포트가 정말 병렬로 물렸는지 보는 항목입니다. 한 포트만 빠뜨려도 그 포트에 꽂은 센서만
안 읽히는데, 출고 시에는 센서를 다 꽂아 보지 않으므로 저항으로 확인합니다.

## 10. 고장 판별

현장에서 통신이 안 될 때 보는 순서입니다.

| 증상 | 먼저 의심할 것 |
|---|---|
| `응답 없음` — 전 센서 | 24 V 가 나오는가(F2), A/B 뒤바뀜, **LK1** |
| `응답 없음` — 특정 센서만 | 그 포트의 결선, 슬레이브 ID 중복 |
| `CRC 불일치` 가 간헐적 | **LK1**, 실드 양단 접지, 종단저항, RS485–AC 이격 |
| 파이 저전압 경고 | G2 출력 전압, USB-C 케이블 굵기·접촉 |
| 화면만 깜빡이다 죽음 | DSI 리본 꺾임 (도어 여닫음) |
| 정전 후 시각이 틀림 | RTC 코인셀, I2C 배선 |
